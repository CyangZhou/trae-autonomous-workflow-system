# 智能导航 SKILL - 对抗 LLM 中间信息遗忘

## 🎯 核心目标

**解决痛点**：LLM 存在"中间信息遗忘"现象——对文档开头和结尾记忆清晰，但严重遗忘中间内容。

**解决方案**：通过三明治结构 + 多位置引用 + 视觉标记，强制核心规则在"高记忆区"多次出现。

---

## 🚨 触发条件

当以下情况发生时，自动激活此 SKILL：

1. **文档优化请求**：用户请求优化长文档结构
2. **记忆问题识别**：检测到 LLM 忽略中间信息
3. **导航系统构建**：需要创建智能目录导航
4. **规则文档编写**：编写需要被 LLM 记忆的规范文档

---

## 📐 核心指令

### 指令1：三明治结构构建

```
输入：原始文档内容
输出：优化后的三明治结构文档

执行步骤：
1. 在文档开头创建「⚡ 30秒速记要点」
2. 在开头添加「📍 核心规则速览」摘要表
3. 在每个章节开头添加「🎯 本章要点（记忆锚点）」
4. 在每个章节结尾添加「🧠 记忆强化区」
5. 在文档结尾添加「📍 快速参考」和「记忆地图」
```

### 指令2：多位置引用网络

```
输入：核心规则列表
输出：引用网络配置

执行规则：
- 核心规则（⭐⭐⭐）：必须在 3+ 个位置出现
- 重要规则（⭐⭐）：必须在 2+ 个位置出现
- 一般规则（⭐）：至少在 1 个位置出现

位置类型：
- [↑ 顶部]：文档开头摘要区
- [中 中间]：章节相关位置
- [↓ 底部]：快速参考区
```

### 指令3：视觉标记系统

```
标记优先级：
【⚠️ 必记】→ 最高优先级 → 3+位置重复
【🎯 关键】→ 高优先级 → 2+位置重复
【📌 重要】→ 中优先级 → 特殊标记
【🔍 详情】→ 正常优先级 → 按需查阅

星级标记：
⭐⭐⭐ → 核心规则，必须掌握
⭐⭐ → 重要规则，需要了解
⭐ → 一般规则，按需查阅
```

## 📊 执行协议

### 步骤1：分析原始文档

1. 读取原始文档内容
2. 提取所有规则条目
3. 评估规则优先级（⭐⭐⭐ / ⭐⭐ / ⭐）
4. 识别章节结构

### 步骤2：生成三明治结构

1. 创建开头摘要区（30秒速记要点 + 核心规则速览）
2. 保留并优化中间内容（添加记忆锚点）
3. 创建结尾速查区（快速参考 + 记忆地图）

### 步骤3：构建多位置引用

1. 核心规则（⭐⭐⭐）：添加到开头、中间、结尾
2. 重要规则（⭐⭐）：添加到开头、结尾
3. 一般规则（⭐）：保持在中间位置

### 步骤4：应用视觉标记

1. 添加星级标记
2. 添加优先级标签
3. 添加记忆强化框

### 步骤5：验证输出

1. 检查所有核心规则是否在 3+ 位置出现
2. 检查引用链接是否正确
3. 检查记忆地图是否完整
