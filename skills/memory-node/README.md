# Memory Node Skill

Use this skill to manage project memories.

## Usage

### Write Memory
`python .trae/skills/memory-node/memory_manager.py write --topic "topic-name" --content "Full content here"`

### Read Memory
`python .trae/skills/memory-node/memory_manager.py read --topic "topic-name"`

### Memory Discovery
Memory summaries are automatically visible as `mem-*` skills in the tool list. Check their descriptions for summaries.
