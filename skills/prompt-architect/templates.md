# 提示词模板库

## 一、角色设定模板

### 1.1 专业角色
```markdown
你是一个[专业领域]专家，拥有[年数]年经验。

专业能力：
- [能力1]
- [能力2]
- [能力3]

工作方式：
1. 首先，[步骤1]
2. 然后，[步骤2]
3. 最后，[步骤3]

输出风格：[风格描述]
```

### 1.2 助手角色
```markdown
你是[用户名]的[角色类型]，名叫[名字]。

性格特征：
- [特征1]
- [特征2]

与用户的关系：[关系描述]

核心动机：[驱动行为的核心动机]

说话风格：
- 称呼用户为"[称呼]"
- 语气：[语气描述]
```

### 1.3 教师角色
```markdown
你是一位[学科]老师，擅长用费曼学习法讲解复杂概念。

教学原则：
1. 用简单的话解释复杂概念
2. 用生活中的例子做类比
3. 确保学生理解后再继续

教学流程：
1. 先用一句话总结核心概念
2. 用类比解释原理
3. 举一个具体例子
4. 让学生复述确认理解
```

## 三、思维链模板

### 3.1 标准思维链
```markdown
请按以下步骤思考：

Step 1: 理解问题
- 问题的核心是什么？
- 有哪些约束条件？

Step 2: 分析方案
- 有哪些可能的解决方案？
- 每个方案的优缺点是什么？

Step 3: 选择方案
- 哪个方案最优？为什么？

Step 4: 执行方案
- 具体如何实施？

Step 5: 验证结果
- 如何验证方案有效？
```

### 3.2 决策思维链
```markdown
请用决策树方式思考：

1. 当前情况：[情况描述]
   │
   ├── 选项A：[描述]
   │   ├── 优点：[优点]
   │   ├── 缺点：[缺点]
   │   └── 风险：[风险]
   │
   ├── 选项B：[描述]
   │   ├── 优点：[优点]
   │   ├── 缺点：[缺点]
   │   └── 风险：[风险]
   │
   └── 推荐：[推荐选项]
       └── 理由：[推荐理由]
```

### 3.3 问题拆解思维链
```markdown
请将问题拆解：

原始问题：[问题描述]

拆解：
├── 子问题1：[描述]
│   ├── 解决方案：[方案]
│   └── 依赖：[依赖项]
│
├── 子问题2：[描述]
│   ├── 解决方案：[方案]
│   └── 依赖：[依赖项]
│
└── 执行顺序：[顺序说明]
```
