云舒的核心特点：

| 特点 | 传统 AI | 云舒 |

## 二、为什么重要？

### 2.1 解决了什么问题？

**痛点一：AI 总是"傻傻地"执行**
- 你说"帮我写个登录功能"
- 传统 AI：写完就结束，不管测试、不管质量
- 云舒：自动拆解任务 → 写代码 → 测试 → 质量检查 → 生成交付文档

**痛点二：每次对话都要重新教**
- 你说"按照之前的风格写"
- 传统 AI：什么风格？我不知道
- 云舒：从记忆库调取你的偏好，保持一致

**痛点三：复杂任务容易乱**
- 你说"重构整个项目"
- 传统 AI：容易迷失、重复、遗漏
- 云舒：自动创建检查点、检测循环、螺旋上升

### 2.2 核心价值

```

│  1. 【省心】自己把事情做好，不打扰你      │
```

## 三、怎么理解？

### 3.1 核心概念一：技能驱动

📌 **什么是"技能"？**

想象乐高积木：
- 每个技能 = 一块乐高积木
- 复杂任务 = 把积木拼起来

**技能示例**：

| 技能名称 | 做什么 | 类比 |
|:---|:---|:---|
| 任务拆解器 | 把大任务拆成小任务 | 切蛋糕 |
| 质量门禁 | 检查代码质量 | 考试评分 |
| 记忆管理 | 存储和读取信息 | 笔记本 |
| 飞书文档大师 | 生成漂亮的文档 | 写作助手 |

💡 **核心价值**：一次创建，永久复用

### 3.2 核心概念二：螺旋循环

📌 **什么是"螺旋循环"？**

想象爬楼梯：
- 线性执行 = 走直线，遇到墙就卡住
- 螺旋循环 = 绕圈上升，总能找到出路

**工作原理**：

```
遇到困难 → 回溯检查点 → 尝试新方法 → 记录成功经验
     ↑                                         ↓
     └─────────────────────────────────────────┘
```

**触发场景**：
- 批量修改文件（>=3个）
- 任务执行超过 10 分钟
- 连续失败 2 次以上

### 3.3 核心概念三：质量门禁

📌 **什么是"质量门禁"？**

想象机场安检：
- 每个环节都要检查
- 不合格就不能通过

**四维检查**：

| 维度 | 检查什么 | 通过标准 |
|:---:|:---|:---|
| 边界处理 | 空值、异常情况 | 覆盖率 >= 80% |
| 专业度 | 代码规范 | 符合标准 |
| 完整性 | 功能是否完整 | 无遗漏 |
| 真实验证 | 实际运行测试 | 全部通过 |

## 五、常见误区

### ❌ 误区1：云舒只是一个代码生成器

✅ **正确理解**：云舒是一个完整的工程系统，包含需求分析、任务拆解、代码实现、质量检查、文档生成全流程。

### ❌ 误区2：每次对话都是独立的

✅ **正确理解**：云舒有记忆系统，会记住你的偏好、成功经验和错误教训。

### ❌ 误区3：复杂任务只能手动拆解

✅ **正确理解**：云舒会自动拆解复杂任务，并通过检查点和螺旋循环确保不迷失。
